# Basic Network Sniffer

## Description

A Python-based network sniffer developed as part of the CodeAlpha Cyber Security Internship.

This project captures and analyzes network packets and displays information such as source IP, destination IP, and protocol.

## Features

- Captures network packets
- Displays source IP address
- Displays destination IP address
- Identifies protocols
- Displays packet information

## Technologies Used

- Python
- Scapy
- Computer Networking
